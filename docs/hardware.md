# ハードウェア（部品・配線・設置）

## 部品

| 部品 | おすすめ | メモ |
| --- | --- | --- |
| 本体 | Raspberry Pi 5（4GB 以上） | Pi 4 でも動くが検出が遅くなる（3〜5 fps 程度の見込み） |
| カメラ | Raspberry Pi Camera Module 3 **Wide**（画角 120°） | 広角のほうが部屋を広く見渡せる。USB カメラでも可 |
| パン・チルト台 | SG90 / MG90S 用の 2 軸ブラケット | 樹脂製の安価なもので十分 |
| サーボ ×2 | **MG90S**（金属ギア） | SG90 でも動くが、ガタが大きく狙いがぶれやすい |
| サーボドライバ | PCA9685 16ch（I2C） | ハードウェア PWM なのでジッタが少ない。GPIO 直結も可（後述） |
| レーザー | 赤色 650nm モジュール **出力 1mW 以下（Class 2 以下）** | 電子工作用は 5mW 品が多いので注意。下の「レーザーの選び方」を参照 |
| トランジスタ | 2SC1815（NPN）＋ 1kΩ 抵抗、または MOSFET モジュール | レーザーの ON/OFF 用 |
| 電源 | Pi 5 用 USB-C 電源（5V 5A）＋ サーボ用 5V 2A 電源 | サーボは別電源にする（Pi の電圧降下・再起動を防ぐ） |
| その他 | microSD（32GB）、ジャンパワイヤ、取り付け用の板・金具 | |

### レーザーの選び方

- **必ず出力 1mW 以下（JIS / IEC の Class 1 または 2）を選んでください。**
  日本で売られているレーザーポインターは PSC マークの付いた 1mW 以下の製品に限られていますが、
  電子工作用の「レーザーダイオードモジュール」は 5mW（Class 3R）のものが多く、猫にも人にも危険です。
- 出力の表記がない・怪しい製品は使わないでください。
- 赤（650nm）が一般的です。猫は赤を見分けにくいとも言われますが、動く光点にはよく反応します。

## 配線

**サーボ（PCA9685 経由）**

```
  Raspberry Pi                PCA9685
  3.3V   (1) ───────────────  VCC
  GPIO2  (3) ───────────────  SDA
  GPIO3  (5) ───────────────  SCL
  GND    (6) ──────┬────────  GND
                   │          V+  ◄──── サーボ用 5V 電源 (+)
                   └──────────────────── サーボ用 5V 電源 (−)   ※GND は必ず共通に
                              ch0 ────── パン用サーボ（左右）
                              ch1 ────── チルト用サーボ（上下）
```

**レーザー（トランジスタで ON/OFF）**

```
  GPIO17 (11) ── 1kΩ ──── B ┐
                            │  2SC1815（NPN）
  レーザー (−) ─────────── C ┤  ※足は平らな面を正面にして左から E・C・B
  GND     (9) ──────────── E ┘
  レーザー (+) ── 5V（Pi の 5V ピン (2)、またはモジュールの定格電圧）
```

- 括弧内の数字は Raspberry Pi の物理ピン番号です。
- PCA9685 の **VCC は 3.3V**（ロジック用）、**V+ はサーボ用の 5V** です。取り違えないでください。
- レーザーは GPIO から直接駆動せず、トランジスタを挟みます（GPIO の電流上限を超えるため）。
- I2C を有効にしておきます: `sudo raspi-config nonint do_i2c 0`（または raspi-config の Interface Options）。
  `sudo i2cdetect -y 1` で `40` が見えれば PCA9685 が認識されています。

### PCA9685 を使わない場合

サーボの信号線を GPIO12（ピン 32）と GPIO13（ピン 33）につなぎ、`config.toml` で
`[servo] backend = "gpio"` にします。部品は減りますが、ソフトウェア PWM のため静止中に
サーボが小刻みに震えることがあります（本ソフトは消灯中にサーボの保持を解除して軽減しています）。

## 設置

```
     壁
     ┃ ◢ カメラ＋レーザー（高さ 2m 以上・部屋の中央に向けて斜め下向き）
     ┃   ＼
     ┃     ＼   ← 斜めに見下ろす
     ┃       ＼
     ┗━━━━━━━━━━━━━━━━━━━━━━━  床（ここで遊ぶ）
```

- **高い壁面（部屋の角が理想）から、部屋の中央に向けて斜め下に**取り付けるのがおすすめです。
  - 物体検出モデルは普通の写真で学習しているため、真上から見下ろすより斜めから見たほうが猫を見つけやすい。
  - パン・チルト台を真下に向けると、真下付近でパンの回転が意味をなさなくなり（特異点）、狙いが不安定になる。
  - 天井に付ける場合も、真下ではなく部屋の中央方向に傾けて取り付けてください。
- カメラとレーザーは**なるべく近くに、同じ向きで**固定します。キャリブレーションで位置関係は自動補正されますが、
  離れていると床以外（ソファの上など高さのある場所）で狙いがずれやすくなります。
- しっかり固定してください。取り付けがずれたら `cattoy calibrate` をやり直します。
- 猫が登って届く場所・ケーブルを噛める場所は避けてください。
- 鏡・窓・テレビ・ガラスのテーブルなど、光を反射する物にレーザーが当たらない向きにします。
