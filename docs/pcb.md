# 中継基板（プリント基板）を EasyEDA で作る

ESP32 ボードを挿して、電源・サーボ・レーザー・有線 LAN 用の口をまとめる基板です。
回路は [hardware.md](hardware.md) の配線と同じで、手配線（ユニバーサル基板）の代わりにプリント基板にします。

## 進め方

| 順番 | やること | 私（Claude）に送ってもらうもの |
| --- | --- | --- |
| 1 | ボードが届いたら寸法を測る（[1. 実測シート](#1-実測シート)） | 測った数値、またはボードの表裏の写真（定規を添えて） |
| 2 | EasyEDA で回路図を描く（[2. 部品表](#2-部品表) と [3. 接続表](#3-接続表) のとおり） | — |
| 3 | ネットリストを書き出して照合する（[4. 回路図の照合](#4-回路図の照合)） | 書き出したネットリストのファイル |
| 4 | 基板に部品を並べて配線する（[5. 基板の決まり](#5-基板の決まり)） | 基板の画面（表・裏・3D 表示）のスクリーンショット |
| 5 | 注文前の確認（[6. 注文前のチェック](#6-注文前のチェック)） | ガーバーファイルの zip（画像にして確認します） |
| 6 | JLCPCB に注文する（[7. 注文の設定](#7-注文の設定)） | — |
| 7 | 基板の外形と穴の位置を元に、ケースを設計する | 外形の寸法と取り付け穴の座標 |

> **先に、ブレッドボードかユニバーサル基板で一度組んで動かす**ことをおすすめします。
> 配線の間違いやピンの思い違いは、プリント基板にしてからだと注文し直しになります（届くまで 1〜2 週間）。

## 1. 実測シート

ボードの製品によって寸法やピンの並びが違うので、**届いた実物で測ってから**基板の寸法を決めます。ノギスがあると確実です。

| 項目 | 測る所 | 値 |
| --- | --- | --- |
| ボードの外形 | 縦 × 横（mm） | |
| ピンヘッダーの本数 | 片側あたり（想定は 22 本） | |
| 列の間隔 | 左右のピンヘッダーの中心どうし（mm。2.54 の倍数のはず） | |
| 1 番ピンの位置 | ボードのアンテナ側の端から、1 番ピンの中心まで（mm） | |
| ピンの並び | ボードの印字を上（アンテナ側）から順に。写真でも可 | |
| アンテナの範囲 | ESP32 モジュールの、金属のふたがない（アンテナの模様がある）部分の長さ（mm） | |
| USB-C の位置 | どちらの端にあるか・2 つの間隔 | |
| カメラの端子 | どこにあるか（表・裏・端） | |
| 裏面の部品 | 裏に背の高い部品がないか | |
| 取り付け穴 | ボード自体に穴があるか・位置 | |
| コンデンサ（手持ち） | 直径と足の間隔（mm） | |

## 2. 部品表

**部品の記号（J1・R1 など）とピン番号は、この表のとおりに付けてください。** 回路図の照合（4.）で使います。

| 記号 | 部品 | 値・型番の例 | 足の形（EasyEDA で探す言葉の例） | ピン番号 |
| --- | --- | --- | --- | --- |
| J1 | ESP32 ボードを挿す口（左） | メスのピンヘッダー 1×22 | `female header 1x22 2.54` | 1 番＝アンテナ側の端 |
| J2 | ESP32 ボードを挿す口（右） | メスのピンヘッダー 1×22 | 同上 | 1 番＝アンテナ側の端 |
| J3 | 5V 入力 | 端子台 2 極（ピッチ 5.08mm） | `KF301-2P` / `DG301-5.0-02P` | 1＝＋5V、2＝GND |
| J4 | パン用サーボ | オスのピンヘッダー 1×3 | `male header 1x3 2.54` | 1＝GND（茶）、2＝5V（赤）、3＝信号（橙） |
| J5 | チルト用サーボ | 同上 | 同上 | 同上 |
| J6 | レーザー | JST XH 2 ピン（抜けにくい） | `B2B-XH-A` | 1＝＋、2＝− |
| J7 | 有線 LAN 用の口（W5500） | メスのピンヘッダー 1×8 | `female header 1x8 2.54` | [hardware.md](hardware.md) の表のとおり（1＝GND … 8＝INT） |
| JP1 | レーザーの電圧の切り替え | オスのピンヘッダー 1×3 ＋ ジャンパーピン | `male header 1x3 2.54` | 1＝5V、2＝レーザー＋、3＝3.3V |
| Q1 | レーザーの ON/OFF | 2SC1815（TO-92） | `2SC1815` | **1＝E、2＝C、3＝B**（下記の注意） |
| R1 | Q1 のベース抵抗 | 1kΩ 1/4W | `axial 0.4` など | 1＝IO47 側、2＝ベース側 |
| R2 | レーザーが勝手に点かないための抵抗 | 10kΩ 1/4W | 同上 | 1＝ベース、2＝GND |
| R3 | W5500 の CS を 3.3V へ | 10kΩ 1/4W | 同上 | 1＝3.3V、2＝CS |
| C1 | サーボ用の電解コンデンサ | 470〜1000µF 10V 以上 | 手持ちの直径・足の間隔に合わせる | **1＝＋**、2＝− |
| F1 | （任意）ヒューズ | 復帰型ヒューズ（ポリスイッチ）保持 2.5A 前後 | `PTC resettable fuse TH` | 1＝端子台側、2＝5V 側 |
| C2 | （任意）W5500 用のパスコン | 0.1µF セラミック | `ceramic capacitor TH 5.08` | 1＝3.3V、2＝GND |
| C3 | （任意）W5500 用のパスコン | 10µF | 同上 | 1＝3.3V（＋）、2＝GND |
| J8 | （任意）外付けの ON/OFF ボタン | オスのピンヘッダー 1×2 か JST XH 2 ピン | | 1＝IO0、2＝GND |

**部品を選ぶときの注意**
- **すべて穴に差し込む部品（スルーホール）**にしています。はんだ付けを自分でできて、JLCPCB の部品実装を頼まずに済みます。
- **Q1 のピン番号**は、ライブラリの部品によって違うことがあります。足の形（フットプリント）を開いて、1・2・3 番が E・C・B になっているか確かめてください。違う場合は、照合スクリプトの表を直すので、どうなっていたかを教えてください。
- **C1 と C3 の「＋」が 1 番**になっている足の形を選んでください（EasyEDA の電解コンデンサは、たいてい 1 番が＋です）。
- **R2 は安全のため**に入れています。電源を入れた直後や書き込み中は GPIO47 の状態が決まらないので、R2 がないとレーザーが一瞬点くことがあります。
- **F1（ヒューズ）**は任意ですが、配線が傷んでショートしたときに、ケーブルやボードが発熱するのを防げます。入れる場合は、端子台と 5V の間に入ります。
- JP1 は、レーザーの定格電圧（3V 用か 5V 用か）に合わせてジャンパーピンを挿します。分かるまでは 3.3V 側にしておくと安全です。

## 3. 接続表

同じ行にあるピンを、すべて 1 本のネットとしてつなぎます。**ネット名は自由です**（照合はつながり方だけを見ます）。
回路図では、線を引く代わりに**ネットラベル**（同じ名前のラベルはつながる）を使うと見やすくなります。

| ネット | つなぐピン |
| --- | --- |
| 5V | J1-21（ボードの 5V）、J3-1（F1 を使うなら F1-2）、J4-2、J5-2、C1-1、J7-3、JP1-1 |
| 5V 入力（F1 を使うときだけ） | J3-1、F1-1 |
| 3V3 | J1-1、J1-2（ボードの 3V3）、J7-2、R3-1、JP1-3、（C2-1、C3-1） |
| GND | J1-22、J2-1、J2-21、J2-22（ボードの GND）、J3-2、J4-1、J5-1、C1-2、J7-1、Q1-1（E）、R2-2、（C2-2、C3-2、J8-2） |
| PAN | J1-20（IO14）、J4-3 |
| TILT | J2-18（IO21）、J5-3 |
| LASER | J2-17（IO47）、R1-1 |
| LASER_B | R1-2、Q1-3（B）、R2-1 |
| LASER_K | Q1-2（C）、J6-2 |
| LASER_A | J6-1、JP1-2 |
| ETH_SCK | J2-7（IO41）、J7-4 |
| ETH_MOSI | J2-6（IO42）、J7-5 |
| ETH_MISO | J2-5（IO2）、J7-6 |
| ETH_CS | J2-4（IO1）、J7-7、R3-2 |
| ETH_INT | J1-13（IO3）、J7-8 |
| BTN（J8 を使うときだけ） | J2-14（IO0）、J8-1 |

**J1・J2 のこれ以外のピンは、どこにもつなぎません。** カメラ・内蔵メモリ・USB などがボードの中で使っています。

### ESP32 ボードのピンの並び（想定）

ESP32-S3-DevKitC-1 と同じ並びを想定しています（Freenove 互換のボードはこの並びのことが多い）。
**届いたボードの印字と必ず見比べてください。** 違っていたら、写真を送ってもらえれば接続表と照合スクリプトを直します。

| --- | --- | --- |
| 1 | 3V3 | GND |
| 2 | 3V3 | IO43（TX） |
| 3 | RST | IO44（RX） |
| 4 | IO4 | **IO1 → ETH_CS** |
| 5 | IO5 | **IO2 → ETH_MISO** |
| 6 | IO6 | **IO42 → ETH_MOSI** |
| 7 | IO7 | **IO41 → ETH_SCK** |
| 8 | IO15 | IO40 |
| 9 | IO16 | IO39 |
| 10 | IO17 | IO38 |

| 12 | IO8 | IO36 |

| 14 | IO46 | IO0（BOOT ボタン → J8） |
| 15 | IO9 | IO45 |

## 4. 回路図の照合

回路図を描き終えたら、基板の配置に進む前に、つながり方が接続表どおりかを機械で確かめます。

1. EasyEDA で回路図を開き、**書き出し（Export）→ ネットリスト（Netlist）** を選ぶ。
   形式は **Protel**（「Altium」「Protel2」と表示されることもある）にして保存する。
2. そのファイルを私に送ってください。こちらで照合して結果をお伝えします。
   Python があれば自分でも確かめられます: `python pcb/check_netlist.py <保存したファイル>`

照合では次のことを見つけられます。
- 足りないつながり・余計なつながり（例: MOSI と MISO の取り違え）
- 隣のピンへのつなぎ間違い（例: IO14 のつもりで IO13 につないでいる）
- 別のネットどうしのショート（例: 5V と GND）
- 部品の付け忘れ

## 5. 基板の決まり

### 配置（仮）

ESP32 ボードの**上下の端（アンテナ側と USB-C 側）は空けて**、部品は左右に並べます。

```
          アンテナ側（基板の外にはみ出させる）
   ┌──────┬──────────────┬──────┐
   │ ○    │J1          J2│    ○ │
   │      │┃  ESP32     ┃│ J7   │← 有線 LAN 用の口
   │ J3   │┃  ボードを   ┃│      │  （J2 の 4〜7 番の横）
   │（5V）│┃  上から挿す ┃│ Q1   │
   │ F1   │┃            ┃│R1 R2 │
   │ C1   │┃            ┃│ JP1  │
   │      │┃            ┃│J4 J5 │← サーボ
   │ ○    │              │ J6 ○ │← レーザー
   └──────┴──────────────┴──────┘
          USB-C 側（ふさがない）
```

寸法が分かったら、この配置を元に具体的な位置を決めます。

### 守ること

| 項目 | 決まり |
| --- | --- |
| 層 | 2 層、厚さ 1.6mm、銅箔 1oz |
| 大きさ | 100 × 100mm 以内（JLCPCB でいちばん安い大きさ） |
| **アンテナ** | **ESP32 モジュールのアンテナの下には銅箔を置かない。** 基板の外にはみ出させるのが一番。はみ出させられない場合は、アンテナの真下とその周り 5mm 以上を、表裏とも銅箔なし（キープアウト）にする |
| 5V・GND の線 | 幅 1.5mm 以上（サーボで 2A 近く流れる）。できれば面（ベタ）で |
| 信号の線 | 幅 0.3mm 程度 |
| GND | 表裏とも空いた所を GND の面（ベタ）で埋め、ビアで表裏をつなぐ |
| C1 | 端子台（J3）とサーボの口（J4・J5）の近くに置く |
| 有線 LAN の線 | J7 は J2 の 4〜7 番の近くに置き、線をなるべく短く（15cm 以内の決まりは、基板の線とジャンパワイヤの合計） |
| 取り付け穴 | M3 用に直径 3.2mm を 4 隅に。端から 4mm 以上離し、座標は 1mm 単位のきりのいい値に（ケースの設計で使う） |
| 背の高い部品 | C1・端子台・ピンヘッダーの高さを控えておく（ケースの設計で使う） |
| シルク（印字） | すべての口に名前（5V IN・PAN・TILT・LASER・LAN）、＋−の向き、サーボの線の色（茶・赤・橙）、JP1 の「5V / 3V3」、基板の版と日付 |

## 6. 注文前のチェック

- [ ] 照合スクリプトが「接続表どおりです」になった
- [ ] EasyEDA の **DRC（デザインルールチェック）** でエラーが 0 件
- [ ] **基板を 1:1 で紙に印刷し、ESP32 ボードとピンヘッダーを当てて、穴の位置が合う**ことを確かめた（いちばん確実な確認方法）
- [ ] 3D 表示で、ESP32 ボードの下に背の高い部品が当たっていない
- [ ] アンテナの下に銅箔がない
- [ ] USB-C の口がふさがれていない
- [ ] C1・C3 の＋、端子台の＋−、サーボの線の色の印字が正しい
- [ ] ガーバーファイルを私に送り、画像で確認した（任意）

## 7. 注文の設定

EasyEDA の「製造ファイルを生成（Fabrication → PCB Fabrication File）」から JLCPCB に送れます。

| 項目 | 設定 |
| --- | --- |
| Base Material | FR-4 |
| Layers | 2 |
| PCB Qty | 5（最小） |
| PCB Thickness | 1.6mm |
| PCB Color | Green（他の色は高くなったり遅くなったりすることがある） |
| Surface Finish | HASL（with lead）か LeadFree HASL |
| Outer Copper Weight | 1oz |
| PCB Assembly | なし（自分ではんだ付けする） |

費用の目安は、基板 5 枚で数百円＋送料 1,000〜2,000 円程度です（時期や送り方で変わります）。
