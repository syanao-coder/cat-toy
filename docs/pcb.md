# 中継基板（プリント基板）を EasyEDA で作る

ESP32 ボードと W5500 Lite を挿して、電源・サーボ・レーザーをまとめる基板です。
回路は [hardware.md](hardware.md) の配線と同じで、手配線（ユニバーサル基板）の代わりにプリント基板にします。

## 進め方

| 順番 | やること | 私（Claude）に送ってもらうもの |
| --- | --- | --- |
| 1 | 寸法を測る（[1. 実測シート](#1-実測シート)） | 測った数値、またはボードの表裏の写真（定規を添えて） |
| 2 | EasyEDA で回路図を描く（[2. 部品表](#2-部品表) と [3. 接続表](#3-接続表) のとおり） | — |
| 3 | ネットリストを書き出して照合する（[4. 回路図の照合](#4-回路図の照合)） | 書き出したネットリストのファイル |
| 4 | 基板に部品を並べて配線する（[5. 基板の決まり](#5-基板の決まり)） | 基板の画面（表・裏・3D 表示）のスクリーンショット |
| 5 | 注文前の確認（[6. 注文前のチェック](#6-注文前のチェック)） | ガーバーファイルの zip（画像にして確認します） |
| 6 | JLCPCB に注文する（[7. 注文の設定](#7-注文の設定)） | — |
| 7 | 基板の外形と穴の位置を元に、ケースを設計する | 外形の寸法と取り付け穴の座標 |

回路図（2〜3）は寸法がなくても描けるので、実測と並行して進められます。

EasyEDA での具体的な操作は [8. 操作の手順](#8-操作の手順easyeda) にまとめています。

## 1. 実測シート

ESP32 ボードと W5500 の外形・ピンの位置は、EasyEDA にある部品（足の形）をそのまま使います。
**部品のライブラリの寸法が実物と違うことがある**ので、注文前に必ず 1:1 の印刷で実物と合わせてください（[6.](#6-注文前のチェック)）。

| 項目 | 内容 |
| --- | --- |
| ESP32 ボード | 片側 20 本、ピンの並びは写真で確認済み（[下の表](#esp32-ボードのピンの並び)）。EasyEDA の「ESP32-S3 WROOM N16R8 CAM」（U1）を使う |
| ESP32 ボードの裏 | microSD スロットだけ（背の高い部品なし）。microSD は IO38〜40 を使うので、これらのピンにはつながない |
| W5500 Lite | 6 本 × 2 列、ピンの並びは写真で確認済み。EasyEDA の「W5500MINI」（W1）を使う |
| コンデンサ（C1） | 直径 8mm × 高さ 12mm。足の間隔は 3.5mm が普通（足の形は `CAP-TH_BD8.0-P3.50` など。実物の足の間隔を確かめる） |

**EasyEDA の部品で確かめてほしいこと**
- U1・W1 の足の形を開いて、**列の間隔が実物と同じ**か（ESP32 は左右の列の中心どうし、W5500 は 2 列の中心どうし）。
- W1 の足の形で、**1 番と 12 番（どちらも GND）が同じ端にある**か（実物は G どうしが同じ端）。

## 2. 部品表

**部品の記号（U1・R1 など）とピン番号は、この表のとおりに付けてください。** 回路図の照合（4.）で使います。

| 記号 | 部品 | 値・型番の例 | 足の形（EasyEDA で探す言葉の例） | ピン番号 |
| --- | --- | --- | --- | --- |
| U1 | ESP32 ボード | ESP32-S3 WROOM N16R8 CAM（基板にはメスのピンヘッダー 1×20 を 2 本付けて挿す） | EasyEDA の部品「ESP32-S3 WROOM N16R8 CAM」 | 左列が上から 1〜20、右列が上から 40〜21（[下の表](#esp32-ボードのピンの並び)） |
| J3 | 5V 入力 | 端子台 2 極、または逆に挿せない口（JST XH 2 ピンなど） | `KF301-2P` / `B2B-XH-A` | 並びは自由（照合で自動判断） |
| J4 | パン用サーボ | オスのピンヘッダー 1×3 | `male header 1x3 2.54` | 並びは自由（照合で自動判断）。5V を真ん中にする |
| J5 | チルト用サーボ | 同上 | 同上 | 同上 |
| J6 | レーザー（記号は H1 でもよい） | ピンヘッダー 1×2 か JST XH 2 ピン（抜けにくい） | `B2B-XH-A` | 並びは自由（照合で自動判断） |
| W1 | W5500 Lite（記号は U3 でもよい） | W5500 Lite（基板にはメスのピンヘッダー 1×6 を 2 本付けて挿す） | EasyEDA の部品「W5500MINI」か「W5500-LITE」 | 1〜6＝GND・GND・MOSI・SCLK・CS・INT。7〜12 は部品によって違う（MINI: MISO・RST・NC・3V3・3V3・GND、LITE: GND・3V3・3V3・NC・RST・MISO） |
| JP1 | （任意）レーザーの電圧の切り替え | オスのピンヘッダー 1×3 ＋ ジャンパーピン | `male header 1x3 2.54` | 1＝5V、2＝レーザー＋、3＝3.3V。使わない場合は、レーザーの＋を定格に合わせて 5V か 3.3V へ直接 |
| Q1 | レーザーの ON/OFF | 2SC1815（TO-92） | `2SC1815`（記号は U2 のままでもよい） | **1＝E、2＝C、3＝B**（下記の注意） |
| R1 | Q1 のベース抵抗 | 1kΩ 1/4W | `axial 0.4` など | 1＝IO47 側、2＝ベース側 |
| R2 | レーザーが勝手に点かないための抵抗 | 10kΩ 1/4W | 同上 | 1＝ベース、2＝GND |
| R3 | W5500 の CS を 3.3V へ | 10kΩ 1/4W | 同上 | 1＝3.3V、2＝CS |
| C1 | サーボ用の電解コンデンサ | 470〜1000µF 10V 以上 | 手持ちの直径・足の間隔に合わせる | **1＝＋**、2＝− |
| F1 | （任意）ヒューズ | 復帰型ヒューズ（ポリスイッチ）保持 2.5A 前後 | `PTC resettable fuse TH` | 1＝端子台側、2＝5V 側 |
| C2 | （任意）W5500 用のパスコン | 0.1µF セラミック | `ceramic capacitor TH 5.08` | 1＝3.3V、2＝GND |
| C3 | （任意）W5500 用のパスコン | 10µF | 同上 | 1＝3.3V（＋）、2＝GND |
| R4 | （任意）W5500 の RST を 3.3V へ | 10kΩ 1/4W | `axial 0.4` など | 1＝3.3V、2＝RST（R3 と番号が逆でもよい） |
| J9 | （任意）外付けの ON/OFF ボタン | オスのピンヘッダー 1×2 か JST XH 2 ピン | | 1＝IO0、2＝GND |

**部品を選ぶときの注意**
- **すべて穴に差し込む部品（スルーホール）**にしています。はんだ付けを自分でできて、JLCPCB の部品実装を頼まずに済みます。
- **ESP32 ボードと W5500 Lite は、基板に付けたメスのピンヘッダーに直接挿します**（ジャンパワイヤ不要）。U1・W1 の足の形の穴に、メスのピンヘッダーをはんだ付けします。
  （手配線の配線図 [hardware.md](hardware.md) の J7・J8 が、ここでの W1 にあたります）
- **Q1 のピン番号**は、ライブラリの部品によって違うことがあります。足の形（フットプリント）を開いて、1・2・3 番が E・C・B になっているか確かめてください。違う場合は、照合スクリプトの表を直すので、どうなっていたかを教えてください。
- **C1 と C3 の「＋」が 1 番**になっている足の形を選んでください（EasyEDA の電解コンデンサは、たいてい 1 番が＋です）。
- **R2 は安全のため**に入れています。電源を入れた直後や書き込み中は GPIO47 の状態が決まらないので、R2 がないとレーザーが一瞬点くことがあります。
- **F1（ヒューズ）**は任意ですが、配線が傷んでショートしたときに、ケーブルやボードが発熱するのを防げます。入れる場合は、端子台と 5V の間に入ります。
- JP1 は、レーザーの定格電圧（3V 用か 5V 用か）に合わせてジャンパーピンを挿します。分かるまでは 3.3V 側にしておくと安全です。

## 3. 接続表

同じ行にあるピンを、すべて 1 本のネットとしてつなぎます。**ネット名は自由です**（照合はつながり方だけを見ます）。
回路図では、線を引く代わりに**ネットラベル**（同じ名前のラベルはつながる）を使うと見やすくなります。

| ネット | つなぐピン |
| --- | --- |
| 5V | U1-20（ボードの 5V）、J3-1（F1 を使うなら F1-2）、J4-2、J5-2、C1-1、JP1-1 |
| 5V 入力（F1 を使うときだけ） | J3-1、F1-1 |
| 3V3 | U1-1（ボードの 3V3）、W5500 の 3V3 の 2 本、R3-1、（JP1-3、C2-1、C3-1、R4-1） |
| GND | U1-21（ボードの GND）、W5500 の GND の 3 本、J3 の GND、J4・J5 の GND、C1-2、Q1-1（E）、R2-2、（C2-2、C3-2、J9-2） |
| PAN | U1-19（IO14）、J4-3 |
| TILT | U1-24（IO21）、J5-3 |
| LASER | U1-25（IO47）、R1-1 |
| LASER_B | R1-2、Q1-3（B）、R2-1 |
| LASER_K | Q1-2（C）、J6-2 |
| LASER_A | J6 の＋、JP1-2（JP1 を使わないなら、5V か 3.3V へ直接） |
| ETH_SCK | U1-37（IO2）、W1-4（SCLK） |
| ETH_MOSI | U1-36（IO42）、W1-3（MOSI） |
| ETH_MISO | U1-35（IO41）、W5500 の MISO（MINI は 7、LITE は 12） |
| ETH_CS | U1-38（IO1）、W1-5（CS）、R3-2 |
| ETH_INT | U1-12（IO3）、W1-6（INT） |
| BTN（J9 を使うときだけ） | U1-28（IO0）、J9-1 |

- **U1 のこれ以外のピンは、どこにもつなぎません。** カメラ・内蔵メモリ・microSD・USB などがボードの中で使っています。
- **W5500 の NC と RST はつなぎません**（RST は R4 で 3.3V へつないでもよい）。W5500 のリセットはファームウェアが通信で行います。
- **ボードの 3V3・5V・GND はそれぞれ 1 本ずつ**しかありません。5V・GND は太い線で U1-20・U1-21 へ。
- 照合スクリプトは、トランジスタが U2・W5500 が U3・レーザーが H1 でも読み替えます。J3〜J6 のピンの並びは、つながっている相手から判断して表示するので、それを基板の印字に使ってください。
- W5500 Lite は 3.3V 専用（V＝3.3V）で、130mA ほど使います。ボードの 3V3 から取ります（有線のときは Wi-Fi を止めて合計を抑えます）。

### ESP32 ボードのピンの並び

EasyEDA の部品（U1）の番号と、届いたボードの印字（写真）を合わせたものです。どちらも上がアンテナ側です。

| U1 の番号 | 左列 | U1 の番号 | 右列 |
| --- | --- | --- | --- |
| 1 | **3V3** | 40 | IO43（TX） |
| 2 | EN（RST） | 39 | IO44（RX） |
| 3 | IO4 | 38 | **IO1 → ETH_CS** |
| 4 | IO5 | 37 | **IO2 → ETH_SCK**（ボード上の LED にもつながっている） |
| 5 | IO6 | 36 | **IO42 → ETH_MOSI** |
| 6 | IO7 | 35 | **IO41 → ETH_MISO** |
| 7 | IO15 | 34 | IO40（microSD） |
| 8 | IO16 | 33 | IO39（microSD） |
| 9 | IO17 | 32 | IO38（microSD） |
| 10 | IO18 | 31 | IO37（内蔵メモリ） |
| 11 | IO8 | 30 | IO36（内蔵メモリ） |
| 12 | **IO3 → ETH_INT** | 29 | IO35（内蔵メモリ） |
| 13 | IO46 | 28 | IO0（BOOT ボタン → J9） |
| 14 | IO9 | 27 | IO45 |
| 15 | IO10 | 26 | IO48（ボード上の RGB LED） |
| 16 | IO11 | 25 | **IO47 → レーザー** |
| 17 | IO12 | 24 | **IO21 → チルト** |
| 18 | IO13 | 23 | IO20（USB） |
| 19 | **IO14 → パン** | 22 | IO19（USB） |
| 20 | **5V** | 21 | **GND** |

**IO2 を SCK にした理由**: IO2 にはボード上の LED がつながっています。W5500 が出す信号（MISO）をこのピンで受けると、LED の分だけ信号が弱まるおそれがあります。ESP32 が出す信号（SCK）なら問題ありません（通信中に LED が点滅しますが、害はありません）。

## 4. 回路図の照合

回路図を描き終えたら、基板の配置に進む前に、つながり方が接続表どおりかを機械で確かめます。

1. EasyEDA で回路図を開き、**書き出し（Export）→ ネットリスト（Netlist）** を選ぶ。
   形式は **Protel**（「Altium」「Protel2」と表示されることもある）にして保存する。
2. そのファイルを私に送ってください。こちらで照合して結果をお伝えします。
   Python があれば自分でも確かめられます: `python pcb/check_netlist.py <保存したファイル>`

照合では次のことを見つけられます。
- 足りないつながり・余計なつながり（例: MOSI と MISO の取り違え）
- 隣のピンへのつなぎ間違い（例: IO14 のつもりで IO13 につないでいる）
- つないではいけないピンへの接続（例: W5500 の NC ピン）
- 別のネットどうしのショート（例: 5V と GND）
- 部品の付け忘れ

## 5. 基板の決まり

### 配置（仮）

寸法が分かったら、配置図を画像で作ります。それまでの考え方は次のとおりです。

- **ESP32 ボードの上下の端（アンテナ側と USB-C 側）は空ける。** アンテナ側は基板の外へはみ出させ、USB-C 側はケーブルを挿せるようにふさがない。
- **W5500 Lite（W1）は右側**、U1 の 35〜38 番（IO41・IO42・IO2・IO1）の横に置き、SPI の線を短くする。LAN の口は基板の端に向け、ケースの穴から LAN ケーブルを挿せるようにする。
- **5V 入力（J3）・F1・C1 は左側の下**、ボードの 5V（U1-20）の近くに置く。
- **サーボの口（J4・J5）・レーザー（J6・Q1・R1・R2・JP1）は右側の下**、IO47・IO21（U1-25・24）の近くに置く。パン（IO14）は左側の U1-19 から線を回す。

### 守ること

| 項目 | 決まり |
| --- | --- |
| 層 | 2 層、厚さ 1.6mm、銅箔 1oz |
| 大きさ | 100 × 100mm 以内（JLCPCB でいちばん安い大きさ） |
| **アンテナ** | **ESP32 モジュールのアンテナの下には銅箔を置かない。** 基板の外にはみ出させるのが一番。はみ出させられない場合は、アンテナの真下とその周り 5mm 以上を、表裏とも銅箔なし（キープアウト）にする |
| 5V・GND の線 | 幅 1.5mm 以上（サーボで 2A 近く流れる）。できれば面（ベタ）で |
| 信号の線 | 幅 0.3mm 程度 |
| GND | 表裏とも空いた所を GND の面（ベタ）で埋め、ビアで表裏をつなぐ |
| C1 | 端子台（J3）とサーボの口（J4・J5）の近くに置く |
| C2・C3 | W5500 の 3.3V（W1-10・11）のすぐ近くに置く |
| 有線 LAN の線 | なるべく短く、ほかの線と並べて長く走らせない（20MHz の信号が流れる） |
| 取り付け穴 | M3 用に直径 3.2mm を 4 隅に。端から 4mm 以上離し、座標は 1mm 単位のきりのいい値に（ケースの設計で使う） |
| 背の高い部品 | C1・端子台・W5500 Lite（LAN の口）・ピンヘッダーの高さを控えておく（ケースの設計で使う） |
| シルク（印字） | すべての口に名前（5V IN・PAN・TILT・LASER・W5500）、＋−の向き、サーボの線の色（茶・赤・橙）、JP1 の「5V / 3V3」、W5500 の向き（LAN の口の側）、基板の版と日付 |

## 6. 注文前のチェック

- [ ] 照合スクリプトが「接続表どおりです」になった
- [ ] EasyEDA の **DRC（デザインルールチェック）** でエラーが 0 件
- [ ] **基板を 1:1 で紙に印刷し、ESP32 ボードと W5500 Lite を当てて、穴の位置が合う**ことを確かめた（いちばん確実な確認方法）
- [ ] 3D 表示で、ESP32 ボードや W5500 Lite の下に背の高い部品が当たっていない
- [ ] アンテナの下に銅箔がない
- [ ] USB-C の口と LAN の口がふさがれていない
- [ ] C1・C3 の＋、端子台の＋−、サーボの線の色、W5500 の向きの印字が正しい
- [ ] ガーバーファイルを私に送り、画像で確認した（任意）

## 7. 注文の設定

EasyEDA の「製造ファイルを生成（Fabrication → PCB Fabrication File）」から JLCPCB に送れます。

| 項目 | 設定 |
| --- | --- |
| Base Material | FR-4 |
| Layers | 2 |
| PCB Qty | 5（最小） |
| PCB Thickness | 1.6mm |
| PCB Color | Green（他の色は高くなったり遅くなったりすることがある） |
| Surface Finish | HASL（with lead）か LeadFree HASL |
| Outer Copper Weight | 1oz |
| PCB Assembly | なし（自分ではんだ付けする） |

費用の目安は、基板 5 枚で数百円＋送料 1,000〜2,000 円程度です（時期や送り方で変わります）。

## 8. 操作の手順（EasyEDA）

メニューの名前は、Std 版と Pro 版、言語の設定で少し違います。主な違いは次の表のとおりです（以下の本文は Pro 版の名前で、括弧内は英語表示のときの名前）。

| 操作 | Std 版 | Pro 版 |
| --- | --- | --- |
| 照合用のネットリスト | ファイル → ネットリストのエクスポート → **PCB設計用Protel/Altium** | ファイル → エクスポート → ネットリスト → Protel |
| 基板に変換 | Design → Convert to PCB（PCB に変換） | 設計 → 回路図を PCB に変換 |
| 回路図の変更を基板へ反映 | PCB の画面で Design → Import Changes | 設計 → PCB を更新 |
| ガーバーの書き出し | Fabrication → PCB Fabrication File (Gerber) | ファイル → 製造ファイル → ガーバー |

> ネットリストの書き出しで **「LTspice for This Sheet」は選ばないでください**。シミュレーション用で、電源の記号がないとエラーになります（回路図の誤りではありません）。

### 8-1. 回路図を照合する

1. 回路図を開いたまま、ネットリストを書き出す。
   - Std 版: **ファイル → ネットリストのエクスポート → PCB設計用Protel/Altium**
   - Pro 版: **ファイル → エクスポート → ネットリスト**（File → Export → Netlist）で、形式に **Protel**（「Protel2」「Altium」と表示されることもある）を選ぶ
2. 保存する。一覧に Protel が無ければ、その画面のスクリーンショットを送ってください。
3. 保存したファイルを、このチャットに添付して送る。照合の結果と、J3〜J6・H1 のピンの並び（印字に使う）をお返しします。

### 8-2. 基板に変換する

1. **設計 → 回路図を PCB に変換**（Design → Update/Convert Schematic to PCB）。新しい PCB の画面が開き、部品が並んで、つなぐべき所に細い線（ラッツネスト）が引かれます。
2. 以後、回路図を直したら、同じメニューの「PCB を更新」で基板に反映します（基板の側で線を直接つなぎ替えない）。

### 8-3. 外形と部品の配置

1. **配置 → 基板外形**（Place → Board Outline）で四角を描く。100 × 100mm 以内、角は半径 2〜3mm の丸めにすると割れにくい。
2. 部品を [5. 基板の決まり](#5-基板の決まり) の考え方で並べる。
   - U1（ESP32）を中央に。**アンテナ側の端を基板の外へはみ出させる**か、アンテナの下を銅箔の禁止領域（Keep-out / 禁止区域）にする。USB-C 側の端はふさがない。
   - U3（W5500）は右上、U1 の 35〜38 番の横に。LAN の口を基板の端に向ける。R3・R4 はその近くに。
   - J3（5V 入力）・C1 は左下、J4（パン）は左側。J5（チルト）・H1（レーザー）・U2・R1・R2 は右下、U1 の 24・25 番の近くに。
   - **U1 の下には背の高い部品（C1・ピンヘッダー）を置かない**（ESP32 ボードが当たる）。
   - 取り付け穴（M3 用、直径 3.2mm）を 4 隅に。**配置 → 穴**（Place → Hole）か、取り付け穴の部品を使う。
3. 迷ったら、この段階のスクリーンショットを送ってください。配置を見ます。

### 8-4. 配線（パターン）

1. **設計 → 設計ルール**（Design → Design Rule）で線の太さを決める。
   - 5V と GND は 1.0〜1.5mm（サーボで 2A 近く流れる）
   - そのほかの信号は 0.3mm、線どうしの間隔は 0.2mm 以上
2. **配線 → 配線**（Route → Track）で、細い線（ラッツネスト）をなぞるように引く。順番は 5V → 信号 → GND の順がやりやすい。
   - SPI（U1 の 35〜38 番 → W5500）はなるべく短く。
   - 表で交差するときは、**ビア**で裏へ回す。
3. **GND は面で埋める**: **配置 → 銅箔エリア**（Place → Copper Area / Copper Region）で基板全体を囲み、ネットを GND にする。表（Top）と裏（Bottom）の両方に作り、空いた所に GND のビアを点々と打って表裏をつなぐ。
4. アンテナの下に銅箔が入っていないことを確かめる（禁止領域があれば自動で避ける）。

### 8-5. 印字（シルク）

- J3 に「＋5V」「GND」、J4・J5 にピンの並び（照合で表示した並び、例「S ＋ −」）、H1 に「＋ −」。
- W5500 の向き（LAN の口の側）、ESP32 の向き（アンテナ側）。
- 基板の名前・版・日付（例「cat-toy v1 2026-10」）。

### 8-6. 確認して書き出す

1. **設計 → DRC チェック**（Design → Check DRC）。エラーが 0 件になるまで直す。
2. **表示 → 3D プレビュー**（View → 3D Preview）で、部品どうしやケースに当たりそうな所がないか見る。
3. **1:1 で印刷**: **ファイル → 印刷**（または PDF に書き出し）で **倍率 100%** にして印刷し、実物の ESP32 ボードと W5500 を当てて、穴の位置が合うか確かめる。
4. **ファイル → 製造ファイル → ガーバー**（Export → PCB Fabrication File (Gerber)）で zip を書き出す。この zip を送ってもらえれば、画像にして確認します。
5. JLCPCB に注文（[7. 注文の設定](#7-注文の設定)）。
6. 基板の外形の寸法と取り付け穴の座標を控える（ケースの設計で使う）。
